# RustPad Document & PDF Studio

*Fast · Lightweight · 100% Native Rust · Designed by Nour Yahyaoui*

Welcome to **RustPad** — your 100% pure-Rust native desktop studio for creating & editing **Microsoft Word (.docx)** and **PDF (.pdf)** files offline with a calm Paper & Daylight light interface.

## 1. Core Capabilities at Your Fingertips

- Open, create, format, and save standards-compliant Microsoft Word (.docx) files.

- Export print-ready vector PDFs in one click or open any existing PDF to edit, merge, split, sign, or compress.

- Press Ctrl+K anywhere to launch the instant Command Palette across 35+ tools.

### 2. Quick Feature Matrix

| Studio Pillar | Key Capabilities | Quick Shortcut |
| --- | --- | --- |
| Word Studio (.docx) | Paginated A4/Letter sheets, styles, tables, headers & spellcheck | Ctrl+N / Ctrl+S |
| PDF Studio (.pdf) | Create PDF, edit text blocks, highlight, sign, merge, split & redact | Ctrl+E / Ctrl+M |
| Power Tools | DOCX <-> PDF converter, offline OCR, Split View & Time-Machine | Ctrl+K |
